# Demo data

`compass-demo.json` is a ready-made Compass export file with 21 sample notes (study notes, interview
prep, a recipe, a shopping list, a few English lines) and their tags.

Load it any time with the **Import notes** button in the side panel. Importing it again changes
nothing: notes that already exist are skipped. Delete the demo notes one by one when you no longer
want them.

Things worth trying after the import: search `zlozonosc` (no Polish letters), `indkes` (a typo),
`sql` (exact tag first, then titles), and filter by the `rozmowa` tag.
